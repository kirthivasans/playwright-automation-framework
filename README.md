# Playwright Automation Framework

A Playwright + JavaScript automation framework built for practicing 
scalable, maintainable test automation — including Page Object Model, 
CI/CD via GitHub Actions, and enterprise-style branching/PR workflows.

## Structure
- `js-framework/` — Playwright test suite (JavaScript)

## Tests
- Login validation
- Invalid username validation
- Invalid password validation

## Tech Stack
- Playwright
- JavaScript
- GitHub Actions (CI)
